# 法要日程カレンダー (houyou-calendar)

命日を入れると、忌日法要(初七日〜四十九日・百箇日)と年忌法要(一周忌〜五十回忌)の日付を、
曜日・六曜・祝日と「前倒しするならこの日」の候補つきで一覧にするツール。

- 公開先: https://hakoniwalab.com/houyou-calendar/
- 年忌早見表: https://hakoniwalab.com/houyou-calendar/hayami/
- ペット版: https://hakoniwalab.com/houyou-calendar/pet/
- 死亡後の手続き期限カレンダー: https://hakoniwalab.com/houyou-calendar/tetsuzuki/
- HAKONIWA LAB 12本目。生まれ日診断に続く2本目の非YMYL

## なぜ作ったか

法要の計算ツールは葬儀社などに多数あるが、調べた範囲(2026-09-19)では
**六曜・祝日・前倒しの候補日・関西式・旧盆・神式・カレンダー登録**を揃えたものがなかった。
六曜と祝日は birthday-fortune で検証済みの計算部品があり、そのまま使える。
「七回忌」「百箇日」「年忌早見表 2027」のように具体的な名詞で検索される題材でもある。

## ファイル

| ファイル | 中身 |
|---|---|
| `js/houyou.js` | 計算の本体。法要の定義、日程表、初盆、早見表、表のHTML |
| `js/app.js` | 画面。入力の保存(localStorage `houyou-calendar:input`)、.ics 書き出し、共有。`window.HOUYOU_PAGE` で設定を上書きできる(ペット版が使う) |
| `pet/index.html` `js/pet.js` | ペットの法要カレンダー。app.js をそのまま使い、pet.js が設定・月命日・お彼岸・お供え花の欄を足す。保存キーは `houyou-calendar:pet`(人の入力とは別) |
| `js/hayami.js` | 早見表ページの「ほかの年を調べる」 |
| `js/astro.js` `js/koyomi.js` `js/holiday.js` | **birthday-fortune からの複製(21a6b6f)**。六曜・旧暦・祝日。直すときは向こうと両方直す |
| `scripts/build.js` | 静的な表を書き出す(index.html の旧盆の表、hayami/index.html) |
| `scripts/hayami.template.html` | 早見表ページの原本。**hayami/index.html を直接編集しない** |
| `test/verify.js` | 検証。本体の js をそのまま読み込む |

```
node test/verify.js      # 検証(114件)
node scripts/build.js    # 年が変わったら流し直す(今年と来年の表になる)
```

## 数え方の約束

| 対象 | 数え方 |
|---|---|
| 忌日(七日ごと) | 命日を1日目。初七日=命日+6日、四十九日=命日+48日 |
| 関西式 | 命日の前日を1日目(七日ごとの法要だけ1日早い)。百箇日と年忌は動かさない |
| 百箇日 | 命日+99日 |
| 年忌 | 一周忌=満1年、三回忌以降は「回忌−1」年後の祥月命日 |
| 神式の霊祭 | 亡くなった日を1日目として10日ごと。翌日祭は2日目 |
| 神式の式年祭 | 満◯年(三年祭=満3年) |
| 2月29日 | うるう年でない年の祥月命日は2月28日 |
| 前倒しの候補 | 当日より前で最も近い「休みのかたまり」(3連休なら3日)。平日の祝日1日だけなら前の週末も足す |
| 三月越し | 四十九日が命日の月から数えて3つめの月に入る。五七日を一覧で目立たせる(次の法要・.icsは四十九日のまま) |
| 初盆 | 四十九日がお盆の初日(13日)より前ならその年、当日以降なら翌年。お盆の後に亡くなれば翌年 |
| 旧盆 | 旧暦7月13日〜15日(閏7月は使わない) |

## ペット版(pet/、2026-09-20追加)

- きっかけ: 日経クロストレンドの見出し「ペットと『悔いなく別れたい』に応えるサービス続々 葬送費用も上昇」。非YMYLで、この計算部品がそのまま使える
- 数え方は人の仏式と同じ(霊園の法要計算も同じ)。節目の顔ぶれだけ `PET_CHUIN` `PET_HYAKKANICHI` `PET_NENKI`(一周忌〜十七回忌。十三回忌あたりで区切ることが多いとされる)。三月越しは出さない
- ペット版だけの欄: 1年目の月命日(`monthlyMemorials`、ない日は月末、12か月目は一周忌と重なるので11回)、次のお彼岸(`upcomingHigan`、霊園の合同供養祭が多い時期)。月命日は .ics にも入る(当日9時に通知)が、家族に送る文面には入れない
- 広告: 提携済みのベルビーフルールの商品リンクで、行き先をペット向けお供え花一覧(`bv-flower.com/SHOP/140938/153938/list.html`)にしている。a8mat は人の版と同じ

## 検証したこと

- 1900〜2100年の全日で、日の通し番号 ⇄ 年月日の往復と曜日が Date と一致
- 旧盆: 公開されている2019〜2030年の沖縄の旧盆(ウンケー)と **12年すべて一致**
- 祝日: holiday.js 側で内閣府CSV(1955〜2027年、1,067件)と全件一致済み
- 「1月1日没 → 四十九日2月18日(関西2月17日)」の例が小さなお葬式の解説と一致

## 死亡後の手続き期限カレンダー(tetsuzuki/、2026-09-21追加)

命日(相続の開始を知った日)から、死亡届・各種届出・相続放棄・準確定申告・相続税・相続登記・もらえるお金の時効まで17件の期限を出す。

- `js/tetsuzuki.js` … 期限の計算と手続きの定義(純粋関数)。`js/tetsuzuki-app.js` が画面。`.ics` の小物は houyou.js に移して共用
- 数え方は**すべて条文で確認**(e-Gov API で取得):
  民法140条(初日不算入)・143条2項(応当日の前日に満了、応当日がなければ月末)・915条(相続放棄3か月)・1048条(遺留分1年)／
  戸籍法43条(戸籍の届出は初日算入)・86条(死亡届7日)／所得税法125条(準確定申告)／相続税法27条(相続税10か月)／
  不動産登記法76条の2(相続登記3年)／国税通則法10条2項・同施行令2条2項(期限が土日祝・12/29〜31なら翌開庁日)／
  健康保険法193条(2年)・国民年金法102条(年金5年・死亡一時金2年)・保険法95条(保険金3年)
- 相続登記は義務化(2024-04-01)より前の相続なら2027-03-31まで(法務省Q&A)。`keika` フラグで注記を出す
- 期限が閉庁日のとき翌開庁日にずらすのは、税務署・家裁・法務局に出すもの(`shift: true`)だけ。死亡届は時間外でも受け付けるのでずらさない
- 検証は test/verify.js の13番(月末・閉庁日・経過措置・並び順まで)。**「知った日」が命日と違うケースは入力で受ける**(画面で説明)
